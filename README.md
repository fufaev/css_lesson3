## «Стилевое оформление веб-страниц: Работа с изображениями, списками и позиционированием»

**Тема:** Применение каскадных таблиц стилей (CSS) для комплексного оформления текстового контента, графики, списков-маркеров и абсолютного позиционирования элементов.

**Цель:** Научиться верстать многоблочные адаптивные структуры, стилизовать интерактивные элементы при наведении (`:hover`), кастомизировать маркеры списков и управлять наложением слоев с помощью `z-index`.

## 🔒 Защита от плагиата (Индивидуальные параметры)

Для успешной сдачи работы **каждый студент обязан настроить проект под себя**:

1. **Именной файл портрета автора:** 
   Возьмите любое изображение для вашего портрета (блок `#me`) в папке `images/` и переименуйте его, назвав **своей фамилией на латинице в нижнем регистре** (например: `ivanov.jpg`). В файле стилей подключайте именно его.
2. **Именной логотип / заголовок:**
   Текст основного заголовка (`.title` или текстовый логотип страницы) должен строго соответствовать формату: `Фотоотчеты | [Ваша Фамилия]`.
3. **Динамический интервал (line-height) списка:**
   Значение межстрочного интервала (`line-height`) для маркированного списка `ul.spisok` рассчитывается индивидуально: **количество букв в вашей фамилии на латинице + 20 пикселей**.
   * *Пример для фамилии Ivanov (6 букв): 6 + 20 = 26px. Ваше свойство: `line-height: 26px;`*

## 📝 Обязательные технические требования

* **HTML-разметка и CSS-блоки:** Стилизация селекторов `body` (центрирование фона `bg.jpg`), `p` (выравнивание по ширине, обнуление margin), классов `.title`, `.podpis`, `.ev` (синяя сплошная рамка для фото галереи) и блоков `.box`.
* **Работа с меню и списками:** Настройка интерактивного меню `.menu a` с изменением цвета при наведении (`:hover`). Кастомизация списка `ul.spisok` с использованием кастомного маркера `list-style-image: url(../../images/list_arrow.gif)`.
* **Позиционирование и слои:** Настройка главного контейнера `#main_block` (относительное позиционирование, выравнивание по центру) и точное наложение портрета автора `#me` поверх контента шапки с помощью абсолютного позиционирования (`position: absolute`) и управления приоритетом видимости (`z-index: 1000`).
* **Валидация:** Полное отсутствие ошибок и предупреждений при проверке кода в W3C Validator.
* **История разработки:** Наличие не менее 4–5 осмысленных коммитов из среды VS Code.
